事業場ノート 1.0

ここから始めてください

まずは導入ガイドを開き、GitHubにアプリを置きます。その後、ご本人のデータ共有先を設定すると、スマホとパソコンで同じ情報を使えます。

導入・操作ガイドを開く →

  1. app：GitHubへアップロードするアプリ一式
  2. app/setup：共有先を準備するための設定ファイル
  3. 検証結果.md：今回確認した動作と、接続後に確認すること
  4. tests・package.json：開発者向けの検証コード
接続先を設定する前は、この端末だけで使う「お試しモード」です。実際の顧客情報を入れる前に、仮の事業場で同期とバックアップを確認してください。

パスワードや秘密キーをチャットへ送る必要はありません。画面の項目がわからないときは、秘密の情報を隠したスクリーンショットで確認できます。
